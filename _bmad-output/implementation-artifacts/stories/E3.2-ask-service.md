# E3.2 — AskService (snapshot-before-STT flow)

> **As dad,** I want to point the camera, then ask the question, so that I can refer to "esto" without re-framing.

## 1. Context

Mirror of DescribeService for the FR-2 path. Critical ordering: **snapshot fires before STT opens** so dad can refer to "esto" in his question. Then UtteranceRouter (E3.1) decides what to do with the transcript. Memory recall path (E5.2) hooks in here once it exists; until then memory routes fall through to the model.

## 3. Acceptance Criteria

- [ ] **AC3.2.1** — `AskService.run()` returns `Promise<Result<AskOutcome, AskError>>`. Order: heartbeat `looking` → snapshot → heartbeat `listening_start` → STT → heartbeat `listening_stop` → utterance route → dispatch.
- [ ] **AC3.2.2** — Snapshot is captured *before* STT opens (AC2.2 from PRD — dad refers to "esto").
- [ ] **AC3.2.3** — Route handling:
  - `repeat` → reads back `SnapshotCache.getLatest()?.narration` via TTS; if none, speaks `errorCopyFor('unknown')`.
  - `extend` → re-queries the gateway with the **same** image (from the cache) + extend prompt ("contame más, hasta 80 palabras"). Speaks the new narration.
  - `memory` → calls `MemoryService.recall(object)` (stub returns `{ freshness: 'miss' }` until E5.2 lands) → on hit, speaks the recall phrasing; on miss, falls through to model.
  - `model` → builds prompt with catalog (`OnboardingService.getCatalog()` graceful fallback) + transcribed question + snapshot, calls gateway, speaks narration.
- [ ] **AC3.2.4** — STT permission denial → `permission_denied_mic` copy + heartbeat `error` + return `err('permission_denied')`.
- [ ] **AC3.2.5** — STT no-speech / timeout → `errorCopyFor('no_speech')` (generic) + return.
- [ ] **AC3.2.6** — Same low-confidence detection as DescribeService via `isLowConfidenceResponse`. Speaks the gentle question; returns `err('low_confidence')`.
- [ ] **AC3.2.7** — Telemetry: writes `usage_events` row with `action: 'ask'` and `error_kind` reflecting the route (`repeat`, `extend`, `memory_hit`, `memory_miss`, or null on model success).
- [ ] **AC3.2.8** — Unit tests cover happy paths for each route, plus the error fallbacks. ≥8 tests.

## 4. Technical Approach

`app/src/services/AskService.ts` (replaces E1.8 skeleton):

```typescript
import { speak } from '@/adapters/tts';
import { listen } from '@/adapters/stt';
import { fire } from '@/adapters/haptics';
import { captureSnapshot } from '@/adapters/camera';
import { chat } from '@/gateways/openrouter';
import { buildSystemPrompt } from '@/prompts/lola';
import { getDb } from '@/adapters/storage';
import { errorCopyFor, isLowConfidenceResponse } from '@/services/errorCopy';
import { route } from '@/services/UtteranceRouter';
import * as OnboardingService from '@/services/OnboardingService';
import * as SnapshotCache from '@/services/SnapshotCache';
import * as MemoryService from '@/services/MemoryService';
import { ok, err, type Result } from '@/utils/result';
import { now } from '@/utils/time';

// ... AskOutcome / AskError types ...

export async function run(): Promise<Result<AskOutcome, AskError>> {
  const t0 = now();
  fire('looking');
  const snap = await captureSnapshot();
  if (!snap.ok) { /* permission_denied / no_camera handling */ }

  fire('listening_start');
  const sttResult = await listen();
  fire('listening_stop');
  if (!sttResult.ok) { /* permission_denied_mic / no_speech handling */ }

  const r = route(sttResult.value);
  switch (r.type) {
    case 'repeat':  return handleRepeat();
    case 'extend':  return handleExtend(snap.value.base64);
    case 'memory':  return handleMemory(r.object, snap.value.base64, sttResult.value);
    case 'model':   return handleModel(snap.value.base64, sttResult.value);
  }
}
```

Each handler follows the DescribeService pattern: heartbeat → action → speak → telemetry → return.
