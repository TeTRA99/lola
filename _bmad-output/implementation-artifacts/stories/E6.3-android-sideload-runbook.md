# E6.3 — Android APK + sideload runbook

> **As Charly,** I want a documented sideload procedure for dad's phone, so that any future build can be installed without rediscovering the steps.

## 1. Context

Android sideload is simpler than iOS — no Apple Dev account, no review, no UDID — but the steps to enable "Install from Unknown Sources" and transfer the APK are easy to forget. This story is purely a runbook + a smoke-test step.

## 4. Runbook content

`docs/runbooks/android-sideload.md`:

```markdown
# Android sideload runbook (E6.3)

## 1. Build the production APK
cd app
npx eas-cli@latest build -p android --profile production

EAS reports a download URL when the build finishes (~10-15 min on free tier).

## 2. Transfer to dad's Android
Three options (pick whichever fits dad's phone):
- USB + adb (cleanest): `adb install path/to/lola.apk`
- AirDrop / share to email / Google Drive link
- Download the URL directly on dad's phone via browser

## 3. First install: enable Install from Unknown Sources
Android Settings → Apps → Special access → Install unknown apps → pick the
transfer source (Chrome, Files, Drive, etc.) → Allow.

## 4. Open & smoke test
- Cold-launch Lola
- Should hear "Hola, listo cuando quieras" in Argentine Spanish within 800ms
- Tap top button (Describe) → grant camera permission → see/hear narration
- Tap bottom button (Ask) → grant mic permission → say "¿qué es esto?" → hear answer

## 5. Subsequent updates
Repeat steps 1-2. Android prompts "Update existing app?" — accept. Data persists.

## 6. Uninstall (rare, but documented for completeness)
Settings → Apps → Lola → Uninstall. Wipes the SQLite DB and all catalog photos.
```
