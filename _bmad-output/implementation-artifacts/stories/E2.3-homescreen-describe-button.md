# E2.3 — HomeScreen Describe button

> **User story:** As dad, I want a big button in the top half of the screen labeled and iconed for "Describe," so that I can find and tap it without seeing well.

## 1. Context

First real dad-facing UI. Replaces the placeholder home in `src/app.tsx`. HomeScreen renders **only** the top button in this story — the Ask button (bottom) lands in E3.3. The CameraHost from E1.5 mounts alongside (hidden) so taps actually capture snapshots.

## 3. Acceptance Criteria

- [ ] **AC2.3.1** — `app/src/screens/HomeScreen.tsx` renders the top 50% of the screen as a single Pressable, edge-to-edge. Bottom 50% is a placeholder (`<View>` with background colour) until E3.3 fills it.
- [ ] **AC2.3.2** — Button contains an icon + Spanish label from `COPY.buttons.describeLabel`. No inline Spanish strings (lint catches this).
- [ ] **AC2.3.3** — Contrast ratio ≥7:1 between the label/icon foreground and the button background. **Measured manually** during sideload, screenshot+result saved to `docs/validation/contrast.md`.
- [ ] **AC2.3.4** — Touch target = full top-half of screen (massively over NFR-3's 88dp minimum).
- [ ] **AC2.3.5** — Tap dispatches `DescribeService.run()`. UI does not block on the result — DescribeService handles its own TTS feedback. Button becomes briefly disabled (~100ms grey-out) on tap to prevent double-fires.
- [ ] **AC2.3.6** — No settings icon, no menu, no gear, no nav bar (AC6.2).
- [ ] **AC2.3.7** — `src/app.tsx` mounts the CameraHost (from E1.5) alongside HomeScreen so `captureSnapshot()` works when the button is tapped.
- [ ] **AC2.3.8** — Visual state: dark background (`#000`), high-contrast button face (light grey `#e8e8e8`), large rounded corners, big icon (~120px) centred above label (~36pt). Concrete design tokens live in a `styles` const in HomeScreen — no separate theme system for v0.9.

### 4.2 Component

`app/src/screens/HomeScreen.tsx`:

```typescript
import { useState } from 'react';
import { Pressable, StyleSheet, Text, View } from 'react-native';
import { COPY } from '@/services';
import * as DescribeService from '@/services/DescribeService';

export function HomeScreen() {
  const [busy, setBusy] = useState(false);

  const onDescribe = async () => {
    if (busy) return;
    setBusy(true);
    try { await DescribeService.run(); }
    finally { setTimeout(() => setBusy(false), 100); }
  };

  return (
    <View style={styles.root}>
      <Pressable
        style={({ pressed }) => [styles.btn, styles.btnTop, pressed && styles.pressed, busy && styles.dim]}
        onPress={onDescribe}
        accessibilityRole="button"
        accessibilityLabel={COPY.buttons.describeLabel}
      >
        <Text style={styles.icon}>📷</Text>
        <Text style={styles.label}>{COPY.buttons.describeLabel}</Text>
      </Pressable>
      <View style={[styles.btn, styles.btnBottom, styles.placeholder]}>
        <Text style={styles.placeholderText}>·</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  root: { flex: 1, backgroundColor: '#000' },
  btn: { flex: 1, alignItems: 'center', justifyContent: 'center', padding: 24 },
  btnTop: { backgroundColor: '#e8e8e8' },
  btnBottom: { backgroundColor: '#1a1a1a' },
  pressed: { opacity: 0.8 },
  dim: { opacity: 0.6 },
  icon: { fontSize: 120 },
  label: { fontSize: 36, fontWeight: '700', color: '#000', marginTop: 16, letterSpacing: 0.5 },
  placeholder: { borderTopWidth: 2, borderTopColor: '#000' },
  placeholderText: { color: '#444', fontSize: 80 },
});
```

The icon is a literal emoji (📷) for v0.9 — no asset pipeline overhead. If iOS / Android render it inconsistently, swap to an SVG in E2.5's polish pass or a follow-up story.
