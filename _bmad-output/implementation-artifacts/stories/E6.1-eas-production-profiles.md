# E6.1 — EAS production profiles + secrets

> **As Charly,** I want production-profile EAS builds for both platforms with `OPENROUTER_API_KEY` provided at build time, so that I can ship a build without baking secrets into source.

## 1. Context

`eas.json` already has dev/preview/production profile skeletons from E1.1. This story finishes them: declares the env var name, documents the `eas secret:create` runbook, and verifies a clean production-profile build invocation.

## 2. References

- **PRD:** [NFR-5 no secrets in repo](../../../planning-artifacts/prds/prd-Lola-2026-05-26/prd.md#5-non-functional-requirements), [NFR-10 distribution](../../../planning-artifacts/prds/prd-Lola-2026-05-26/prd.md#5-non-functional-requirements)
- **Architecture:** [§7.3 secrets management](../../../planning-artifacts/architecture/architecture-Lola-2026-05-26/architecture.md#73-secrets-management)

## 3. Acceptance Criteria

- [ ] **AC6.1.1** — `eas.json` `production` profile sets `env.EXPO_PUBLIC_OPENROUTER_API_KEY` from EAS secret store. Android emits APK (not AAB).
- [ ] **AC6.1.2** — `docs/runbooks/eas-secrets.md` documents `npx eas secret:create --scope project --name EXPO_PUBLIC_OPENROUTER_API_KEY --value sk-or-v1-...` and how to rotate.
- [ ] **AC6.1.3** — `eas build -p android --profile production --non-interactive` is the documented command. Whether the build actually executes in this story is gated on the EAS Free tier's 15-builds/month — runbook gives the command but doesn't require Charly to spend a build credit here.
- [ ] **AC6.1.4** — Sanity test: `git grep` confirms no `sk-or-v1-` strings in the repo (excluding `.env.local.example`).

## 4. Technical Approach

`eas.json` update:

```json
{
  "build": {
    "production": {
      "ios": { "autoIncrement": true },
      "android": { "buildType": "apk", "autoIncrement": true },
      "env": {
        "EXPO_PUBLIC_OPENROUTER_API_KEY": "$EXPO_PUBLIC_OPENROUTER_API_KEY"
      }
    }
  }
}
```

(EAS reads `$NAME` as a reference to the secret of that name in the EAS secret store.)

Plus `docs/runbooks/eas-secrets.md`.
