# E5.2 — Memory recall hit path

> **As dad,** I want to ask *"¿dónde está mi cepillo?"* and get an answer from what Lola has already seen, so that I don't need to point the camera at empty rooms.

## 1. Context

E5.4 maps dad's noun to an `object_id`. This story queries `sightings` for the most recent row with that object_id and produces the Spanish answer phrasing. E5.3 will overlay the freshness-window policy on top — for now this story just returns the most recent sighting and lets the consumer decide what to say.

## 4. Technical Approach

`app/src/utils/relativeTime.ts`:

```typescript
// "hace 2 horas" style — Argentine Spanish.
const MIN = 60_000;
const HOUR = 60 * MIN;
const DAY = 24 * HOUR;

export function ago(fromMs: number, nowMs: number = Date.now()): string {
  const delta = Math.max(0, nowMs - fromMs);
  if (delta < MIN) return 'hace un momento';
  if (delta < HOUR) {
    const m = Math.floor(delta / MIN);
    return `hace ${m} minuto${m === 1 ? '' : 's'}`;
  }
  if (delta < DAY) {
    const h = Math.floor(delta / HOUR);
    return `hace ${h} hora${h === 1 ? '' : 's'}`;
  }
  const d = Math.floor(delta / DAY);
  return `hace ${d} día${d === 1 ? '' : 's'}`;
}
```

`MemoryService.recall` implementation:

```typescript
export async function recall(noun: string): Promise<RecallOutcome> {
  const objectId = await resolveObjectFromUtterance(noun);
  if (objectId === null) return { freshness: 'miss' };
  try {
    const db = await getDb();
    const row = await db.getFirstAsync<Sighting>(
      'SELECT id, object_id, observed_at, snapshot_uri, room_hint, source_action, excerpt FROM sightings WHERE object_id = ? ORDER BY observed_at DESC LIMIT 1',
      [objectId],
    );
    if (!row) return { freshness: 'miss' };
    return { freshness: 'fresh', sighting: row };
  } catch {
    return { freshness: 'miss' };
  }
}
```

AskService.handleMemory rewrite — speaks the recall phrasing on hit.

## 6. Risks

- **Stale snapshots referenced by sightings** — if the LRU cache evicted the snapshot file, the URI in the sighting is dangling. Acceptable; the spoken phrasing doesn't depend on the file existing.
- **Relative-time wording** — "hace un momento" sub-1-minute vs. "hace 0 minutos" looks worse. The string ladder above is dad-friendly.
