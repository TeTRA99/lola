# E3.4 — Known-object catalog injection

> **As dad,** I want Lola to know my mate jar from a generic jar, so that she answers in my words for my things.

## 1. Context

`buildSystemPrompt(catalog)` (E2.1) already inlines the catalog when present. AskService (E3.2) already calls `OnboardingService.getCatalog()` and passes the result through. **The wiring is done.** This story exists to:

1. Add an integration-style test that verifies the catalog block actually reaches the model call (rather than being silently dropped).
2. Add a helper for the Lola response → catalog-display-name substitution: when the model returns `{ canonical: "cepillo_de_papa" }`, the consumer can swap "un cepillo" → "tu cepillo" before TTS.

## 4. Technical Approach

`app/src/services/CatalogResolver.ts`:

```typescript
import type { ObjectCatalog } from '@/services/OnboardingService';
import type { LolaObject } from '@/gateways/openrouter';

export function resolveDisplayName(canonical: string, catalog: ObjectCatalog): string | null {
  return catalog.find(o => o.canonical_name === canonical)?.display_name ?? null;
}

export function applyCatalogNarration(
  narration: string,
  objects: LolaObject[],
  catalog: ObjectCatalog,
): string {
  let out = narration;
  for (const o of objects) {
    const resolved = resolveDisplayName(o.canonical, catalog);
    if (!resolved || resolved === o.display) continue;
    // Replace first occurrence of the model's display with the catalog's.
    out = out.replace(o.display, resolved);
  }
  return out;
}
```

Edge cases:
- Model's display matches the catalog display exactly → no-op.
- Model's display is "una taza" but catalog has "tu taza" → substitute.
- Display appears multiple times → only first is replaced (safer; second occurrence may be coincidental).

## 6. Risks

- **Substitution false positives:** model emits "una taza", catalog has "la taza" — substitution produces "estás frente a la taza, hay también una taza azul" (the second taza is unrelated). Acceptable for v0.9; if Charly observes weird output, switch to a more targeted regex or scope substitution to the first sentence only.
