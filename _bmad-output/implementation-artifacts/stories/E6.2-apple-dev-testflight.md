## 4. Charly-side runbook (this is the story's deliverable)

`docs/runbooks/testflight.md`:

```markdown
# TestFlight runbook (E6.2)

## 1. Apple Developer Program enrollment ($99/yr)
- Sign in at https://developer.apple.com with your Apple ID
- Enroll as an individual ($99/yr). 1-2 day identity verification window.
- Once approved, you'll get a Team ID — note it down.

## 2. App Store Connect app create
- Go to https://appstoreconnect.apple.com → My Apps → +
- Bundle ID: com.carlosbernardi.lola (matches app.json)
- Pick a temporary name (you can rename in TestFlight)
- Note the App Store Connect App ID (numeric) from the URL.

## 3. EAS Submit config
Update `app/eas.json`:
{
  "submit": {
    "production": {
      "ios": {
        "appleId": "your-apple-id@example.com",
        "ascAppId": "1234567890"
      }
    }
  }
}

## 4. First submit
cd app
npx eas-cli@latest credentials   # interactive — let EAS manage signing
npx eas-cli@latest build -p ios --profile production
npx eas-cli@latest submit -p ios --latest

## 5. TestFlight onboarding
- App Store Connect → TestFlight → Internal Testing → add your Apple ID as tester
- Wait for the build to appear (~5-15 min after submit)
- Open TestFlight app on your iOS device → install Lola
```
