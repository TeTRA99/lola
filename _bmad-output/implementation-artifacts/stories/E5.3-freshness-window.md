# E5.3 — Freshness-window logic

> **As a developer,** I want the recall path to respect NFR-8's three-tier freshness window, so that Lola doesn't claim certainty about a sighting from last week.

## 1. Context

NFR-8 says:
- **<24h** → confident: `"Lo vi hace 2 horas en la cocina"`
- **24–72h** → hedged: `"Ayer lo vi en el baño, pero hace rato"` (different lexical hedge)
- **>72h** → miss (fall through to live model call)

This story overlays the time check on top of E5.2's recall result. Thresholds come from `CONFIG.MEMORY_FRESH_HOURS` (24) and `CONFIG.MEMORY_HEDGE_HOURS` (72).

## 3. Acceptance Criteria

- [ ] **AC5.3.1** — `MemoryService.recall(noun)` classifies the sighting age:
  - `observed_at` within last `CONFIG.MEMORY_FRESH_HOURS` (24h) → `freshness: 'fresh'`
  - within last `CONFIG.MEMORY_HEDGE_HOURS` (72h) → `freshness: 'hedged'`
  - older than `CONFIG.MEMORY_HEDGE_HOURS` → `freshness: 'miss'` (fall-through)
- [ ] **AC5.3.2** — AskService.handleMemory phrasing changes by freshness:
  - `fresh`: `"Lo vi hace {ago} en {room}"` / `"Lo vi hace {ago}"`
  - `hedged`: `"Hace un tiempo lo vi en {room}, pero puede haberse movido"` / `"Lo vi hace {ago}, pero puede haberse movido"`
  - `miss` (timeout-aged): falls through to model with the original utterance.
- [ ] **AC5.3.3** — Unit tests cover all three age buckets with fixed clock injection (`Date.now` mock or `nowMs` parameter).

## 4. Technical Approach

```typescript
import { CONFIG } from '@/config';
const HOUR = 3600_000;

export async function recall(noun: string, nowMs: number = Date.now()): Promise<RecallOutcome> {
  const objectId = await resolveObjectFromUtterance(noun);
  if (objectId === null) return { freshness: 'miss' };
  const db = await getDb();
  const row = await db.getFirstAsync<Sighting>(
    'SELECT id, object_id, observed_at, snapshot_uri, room_hint, source_action, excerpt FROM sightings WHERE object_id = ? ORDER BY observed_at DESC LIMIT 1',
    [objectId],
  );
  if (!row) return { freshness: 'miss' };

  const ageH = (nowMs - row.observed_at) / HOUR;
  if (ageH <= CONFIG.MEMORY_FRESH_HOURS) return { freshness: 'fresh', sighting: row };
  if (ageH <= CONFIG.MEMORY_HEDGE_HOURS) return { freshness: 'hedged', sighting: row };
  return { freshness: 'miss' };
}
```
