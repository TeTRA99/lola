# E1.2 — `es-AR` locale + CopyModule skeleton

> **User story:** As a developer, I want a single Spanish-copy module containing every dad-facing string, so that voseo, gentle-question errors, and brand consistency (FR-6) are enforced at one place.

## 1. Context

FR-6 (companion frame) is the v0.9 moat per the brief. Its enforcement is editorial — a single source of every Spanish line the user ever sees, with a lint rule guarding voseo and a convention that no other module emits Spanish string literals. This story creates that source; later stories *use* it (E1.3 reads the greeting; E2.5 wires the error copy; etc.).

This story does **not** wire any copy to any UI. It produces the typed `COPY` object, the lint test, and the locale wiring at boot.

## 3. Acceptance Criteria

- [ ] **AC1.2.1** — `app/src/services/CopyModule.ts` exports a typed `COPY` const with every string listed in §6 below. Each key is named for its purpose (not its literal content), e.g. `COPY.greeting`, `COPY.errors.lowConfidence`.
- [ ] **AC1.2.2** — Every value is Argentine Spanish (voseo). A lint test (`app/src/services/__tests__/copy.voseo.test.ts`) iterates the entire flat copy tree and fails if any string matches the forbidden second-person Iberian forms: `\btú\b`, `\bte\b` (when used as Spanish pronoun, not as the English word "te"), `\btienes\b`, `\bpuedes\b`, `\bquieres\b`, `\beres\b`. False positives on borrowed English are unlikely in a copy module that's 100% Spanish.
- [ ] **AC1.2.3** — `app/app.json` sets `expo.locales` defaults / `extra.locale: "es-AR"` (per Expo SDK 56 conventions), so `Localization.getLocales()` returns `es-AR` as primary on first launch in the dev build. (Doesn't override the user's device locale globally — just declares the app's intended primary.)
- [ ] **AC1.2.4** — `app/src/services/CopyModule.ts` carries no logic — pure data. A `Copy` type is exported via `export type Copy = typeof COPY`.
- [ ] **AC1.2.5** — A lint rule (custom ESLint rule or simple `no-restricted-syntax` config) in `app/.eslintrc.cjs` warns when a string literal containing Spanish-looking characters (`á|é|í|ó|ú|ñ|¿|¡`) appears in `src/**/*.{ts,tsx}` *outside* `src/services/CopyModule.ts` and `src/services/__tests__/copy.*`. Warning, not error — the dev agent fixes by relocating the string to CopyModule.
- [ ] **AC1.2.6** — `npm test` (Jest, configured by `create-expo-app`) runs `copy.voseo.test.ts` and exits 0.

## 4. Technical Approach

### 4.1 Module shape

`app/src/services/CopyModule.ts`:

```typescript
export const COPY = {
  greeting: 'Hola, listo cuando quieras.',
  repeatTrigger: 'Lola, ¿otra vez?',
  extendTrigger: 'Lola, contame más',
  errors: {
    lowConfidence: 'No estoy segura — ¿podés acercarte un poquito?',
    noNetwork: 'No tengo señal ahora — ¿probamos en un ratito?',
    cameraPermission: 'Necesito ver para ayudarte — ¿me dejás usar la cámara?',
    micPermission: '¿Me dejás escucharte?',
    generic: 'Algo se me cruzó — ¿lo intentamos de nuevo?',
  },
  buttons: {
    describeLabel: 'Describir',
    askLabel: 'Preguntar',
  },
} as const;

export type Copy = typeof COPY;
```

`as const` on the object IS appropriate here — every value is a literal string, downstream code wants the literal types (e.g. for exhaustive switch over error kinds).

### 4.2 Voseo lint test

`app/src/services/__tests__/copy.voseo.test.ts`:

```typescript
import { COPY } from '../CopyModule';

function flatten(obj: unknown, path: string[] = []): { path: string; value: string }[] {
  if (typeof obj === 'string') return [{ path: path.join('.'), value: obj }];
  if (obj && typeof obj === 'object') {
    return Object.entries(obj).flatMap(([k, v]) => flatten(v, [...path, k]));
  }
  return [];
}

const FORBIDDEN = [
  /\btú\b/i,
  /\btienes\b/i,
  /\bpuedes\b/i,
  /\bquieres\b/i,
  /\beres\b/i,
];

describe('CopyModule voseo enforcement', () => {
  for (const { path, value } of flatten(COPY)) {
    test(`"${path}" uses voseo, not tuteo`, () => {
      for (const pat of FORBIDDEN) {
        expect(value).not.toMatch(pat);
      }
    });
  }
});
```

Note: `\bte\b` is deliberately excluded — it's a legitimate voseo object pronoun (`te dejo`, `te ayudo`). Tuteo detection focuses on conjugated verbs (`tienes`, `puedes`) which are unambiguous.

### 4.3 Locale wiring

`app/app.json`:

```json
{
  "expo": {
    "name": "Lola",
    "slug": "lola",
    "newArchEnabled": true,
    "locales": {},
    "extra": { "primaryLocale": "es-AR" }
  }
}
```

`expo-localization` is a follow-on package (added in E1.3 alongside `expo-speech`). For this story, the `extra.primaryLocale` is documentation-only — downstream stories read it.

### 4.4 ESLint rule

`app/.eslintrc.cjs` add:

```js
module.exports = {
  // ... rest of generated config ...
  overrides: [
    {
      files: ['src/**/*.{ts,tsx}'],
      excludedFiles: ['src/services/CopyModule.ts', 'src/services/__tests__/copy.*'],
      rules: {
        'no-restricted-syntax': ['warn', {
          selector: "Literal[value=/[áéíóúñ¿¡]/]",
          message: 'Spanish strings must live in CopyModule, not inline.'
        }]
      }
    }
  ]
};
```
